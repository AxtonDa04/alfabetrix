CREAR MODAL DE ACTIVACIÓN DE VOZ PARA CHROME MÓVIL — ALFABETRIX

Problema:
En Chrome móvil la voz TTS no se escucha porque speechSynthesis puede quedar bloqueado hasta que el usuario interactúa con la página.

Objetivo:
Crear un componente reutilizable tipo modal/popup para pedir al usuario activar la voz. Debe mostrarse encima de toda la app, con z-index alto, fondo oscuro al 65% de opacidad y estilo visual consistente con ALFABETRIX.

IMPORTANTE:
No tocar diseño general de la app.
No romper navegación.
No romper Supabase.
No hacer commit.
No hacer push.

==================================================
1. CREAR COMPONENTE
==================================================

Crear archivo:

src/components/VoicePermissionModal.jsx

Comportamiento:

- Detectar si el usuario está en Chrome móvil.
- Si NO es Chrome móvil, no mostrar nada.
- Si ya existe en localStorage:
  alfabetrix_voice_permission = "accepted"
  o
  alfabetrix_voice_permission = "rejected"
  no mostrar nada.
- Si es Chrome móvil y no hay decisión guardada, mostrar modal.

Diseño:

- Overlay fixed inset-0
- Fondo negro con opacidad 65%
- z-index muy alto, por ejemplo z-[9999]
- Card centrada
- Estilo cálido de ALFABETRIX:
  - fondo beige/blanco
  - bordes redondeados grandes
  - sombra suave
  - título en guinda
  - texto claro y cordial
  - botón aceptar guinda
  - botón rechazar outline o neutro
- Sin botón X / close.
- Solo se cierra con:
  - Rechazar
  - Aceptar

Texto sugerido:

Título:
Activar voz de apoyo

Mensaje:
Para que ALFABETRIX pueda leer instrucciones y actividades en voz alta, toque Aceptar. Esto ayuda a escuchar cada paso con calma.

Texto secundario:
Puede continuar sin voz si lo prefiere.

Botones:
- Rechazar
- Aceptar

==================================================
2. FUNCIÓN DE DESBLOQUEO DE VOZ
==================================================

Modificar o usar src/lib/tts.js

Agregar export:

unlockVoice()

Debe:
- Verificar window.speechSynthesis
- Crear una SpeechSynthesisUtterance corta
- Texto sugerido:
  "Voz activada."
- lang = "es-MX"
- rate = 0.82
- pitch = 1.08
- volume = 0.01 o 0.2 según funcione mejor
- Usar la misma selección de voz que speak()
- Ejecutar speechSynthesis.speak(utterance) dentro del click del botón Aceptar
- Guardar:
  localStorage.setItem("alfabetrix_voice_unlocked", "1")
  localStorage.setItem("alfabetrix_voice_permission", "accepted")
- Devolver true si pudo intentar activar

Si el usuario rechaza:
localStorage.setItem("alfabetrix_voice_permission", "rejected")
localStorage.removeItem("alfabetrix_voice_unlocked")

==================================================
3. DETECCIÓN CHROME MÓVIL
==================================================

En el componente usar algo como:

const ua = navigator.userAgent || "";

const isMobile =
  /Android|iPhone|iPad|iPod/i.test(ua);

const isChrome =
  /Chrome|CriOS/i.test(ua) &&
  !/Edg|OPR|SamsungBrowser/i.test(ua);

const shouldShow =
  isMobile &&
  isChrome &&
  !localStorage.getItem("alfabetrix_voice_permission");

No romper si navigator no existe.

6. AJUSTAR speak()
==================================================

En src/lib/tts.js revisar speak(text):

- Si está en Chrome móvil y localStorage alfabetrix_voice_permission === "rejected", no hablar.
- Si está en Chrome móvil y no existe alfabetrix_voice_unlocked, evitar autoplay.
- Pero si speak() es llamado desde un botón manual de "Escuchar", debe intentar hablar normalmente.
- No lanzar errores.
