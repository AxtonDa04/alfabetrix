1Resumen Ejecutivo

¿Qué es ALFABETRIX?

ALFABETRIX es una aplicación web educativa diseñada para enseñar a leer y escribir a adultos mayores, especialmente aquellos con nula o escasa educación formal. El proyecto es una iniciativa escolar comunitaria 2026 del CONALEP Ixtapaluca, basada en el programa "Renacer Letras". La interfaz está pensada deliberadamente para personas con dificultades de visión o poca familiaridad con la tecnología: botones grandes, fuentes ajustables, retroalimentación por voz y un flujo simple.

¿Para quién está hecha?

Adultos mayores de comunidades como Ixtapaluca que no saben leer o tienen habilidades lectoras muy básicas. La app está diseñada por y para un contexto de bajo nivel tecnológico: celulares sencillos, redes lentas y usuarios sin experiencia digital.

¿Qué problema resuelve?

El analfabetismo en adultos mayores en México. Ofrece un método progresivo (vocales → consonantes → sílabas → palabras → frases → comprensión) con retroalimentación por voz (TTS), pistas visuales, mensajes motivacionales y un sistema de estrellas para motivar la continuidad.

Estado actual del proyecto

La app compila sin errores, el servidor de desarrollo levanta correctamente y la conexión con Base44 está activa vía SDK. Los 6 módulos educativos tienen ejercicios predefinidos y generación dinámica con IA (InvokeLLM). El único juego implementado es el de Memoria; los 4 juegos restantes están marcados como "Próximamente". El flujo principal Splash→Perfil→Menú→Módulo→Actividad→Resultados→Progreso está completamente implementado.

Partes que dependen de servicios externos

  • Base44 SDK: Persistencia de datos (UserProfile, Progress, Reward), autenticación de usuarios y generación de ejercicios con IA (InvokeLLM). Sin conexión a Base44, la app opera con ejercicios predefinidos pero no guarda progreso.
  • Web Speech API (TTS): Requiere soporte del navegador. Funciona en Chrome y Edge modernos; puede fallar en browsers antiguos o iOS Safari sin configuración adicional.
  • Google Fonts: La fuente Poppins se carga desde fonts.googleapis.com. Sin internet, cae a la pila de fuentes del sistema.

4Arquitectura del Proyecto

Flujo de arranque

index.html→ main.jsx→ App.jsx→ AuthProvider→ QueryClientProvider→ BrowserRouter→ AuthenticatedApp→ Routes

Inicialización

index.html define el elemento <div id="root">. main.jsx monta la app con ReactDOM.createRoot e importa los estilos globales (index.css). Toda la app está envuelta en <App />.

Manejo de autenticación (AuthContext)

AuthProvider en src/lib/AuthContext.jsx intenta llamar a db.auth.me() al montar. Si hay sesión activa en Base44, obtiene el usuario y marca isAuthenticated=true. Si no hay sesión, continúa sin bloquear (el flujo Splash → CreateProfile maneja usuarios no autenticados). El componente AuthenticatedApp en App.jsx controla qué se muestra según el estado de auth.

Layout global (AppLayout)

AppLayout.jsx es el layout compartido para todas las rutas excepto Splash y 404. Aplica dinámicamente la clase de tamaño de fuente (text-xl, text-2xl) y la clase de alto contraste (high-contrast) leídas desde useSettings(), que persiste en localStorage.

Conexión con Base44

Existe un único punto de conexión en src/api/base44Client.js. El cliente se crea con createClient() del paquete @base44/sdk, pasando el appId y una api_key en headers. Todos los archivos que necesitan acceso a datos importan { db } desde este módulo.

import { createClient } from '@base44/sdk';
const base44 = createClient({
  appId: "6a0f9d****",        // ID real ocultado
  headers: { "api_key": "759ae6****" }  // Key real ocultada
});
export const db = base44;
export default base44;
